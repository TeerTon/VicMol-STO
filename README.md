# СТО VicMol — сайт автосервісу

Адаптивний сайт-візитівка СТО VicMol із трьома окремими сторінками: головною, переліком послуг і сторінкою контактів. Інтерфейс українською мовою; верстка створена на HTML5 і CSS3, інтерактивність — на чистому JavaScript без UI-фреймворків.

## Стек

- HTML5, CSS3 (Flexbox, Grid, CSS-змінні, адаптивні стилі)
- JavaScript ES6+
- Google Fonts (Manrope та DM Sans) — опційне зовнішнє завантаження шрифтів
- SVG favicon

## Локальний запуск

1. Відкрийте папку проєкту.
2. Запустіть `index.html` у сучасному браузері.
3. Для локального HTTP-сервера, якщо він потрібен, виконайте з папки проєкту:

   ```bash
   python -m http.server 8000
   ```

4. Перейдіть у браузері на `http://localhost:8000`.

Сторінки `services.html` і `contact.html` доступні через навігацію сайту або за прямими адресами.

## Що працює

- Адаптивне мобільне меню з керуванням клавішею Escape.
- Калькулятор орієнтовної вартості робіт із вибором типу автомобіля.
- Фільтр послуг за категоріями без перезавантаження.
- FAQ на елементах HTML `<details>`.
- Перевірка обов'язкових полів форм і номера телефону формату `+380XXXXXXXXX`.
- Форма показує результат перевірки в браузері. **Відправлення, збереження або передавання заявки не реалізоване:** перед запуском потрібно підключити серверний endpoint чи сервіс обробки форм і налаштувати політику конфіденційності.

## Дані, які треба підтвердити перед публікацією

У власника не були надані адреса СТО, телефон, графік роботи, затверджений прайс і умови гарантії. Сторінки прямо позначають ці дані як незаповнені; ціни в `services.html` та калькуляторі — лише демонстраційні орієнтири, які потрібно затвердити. Також варто додати підтверджені відгуки клієнтів і перевірене посилання на мапу.

## Файли

- `index.html` — головна, переваги, популярні послуги, калькулятор і форма запису.
- `services.html` — каталог і фільтр послуг, орієнтовні ціни та FAQ.
- `contact.html` — контактний блок, макет мапи та форма запиту.
- `styles.css` — спільні стилі та адаптивна верстка.
- `script.js` — меню, калькулятор, фільтрація та валідація форм.
- `favicon.svg` — векторна іконка сайту.
